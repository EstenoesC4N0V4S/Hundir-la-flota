
# 🚢 Hundir la Flota

Juego clásico de **Hundir la Flota** desarrollado con **HTML5, CSS3, JavaScript y Bootstrap**.

El proyecto recrea el clásico juego de estrategia naval con una interfaz sencilla, responsive y una estética inspirada en el mar. 🌊

## 🎮 Cómo jugar

1. Comienza la partida.
2. Los barcos se colocan **automáticamente de forma aleatoria** en los tableros.
3. Selecciona una casilla del tablero enemigo para realizar un disparo.
4. Comprueba si has conseguido un **impacto** o has fallado.
5. Continúa realizando disparos para localizar y hundir los barcos enemigos.
6. ¡Intenta hundir toda la flota rival!
